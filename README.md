# Simon Says

A memory game with four colour pads and a growing sequence.

## Features

- Four pads with their own tones, generated with the Web Audio API
- The sequence grows by one step each round
- Round counter and a best score saved in local storage
- Start or restart at any time
- Wrong pad ends the run and reveals the round reached

## Running it

Open `index.html` in a browser. Audio starts after the first interaction, as browsers require.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour and sound
```

## Tech

Plain HTML, CSS and JavaScript with the Web Audio API.
